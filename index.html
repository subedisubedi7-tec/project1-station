Substation Switchyard Architecture & Single Line Diagram

Air Insulated Substation (AIS) topology featuring One-and-a-Half Breaker (400 kV) and Double Main + Transfer Bus (220/132 kV) schemes.

400 kV Switchyard EHV Grid

  • Busbar Scheme: 1½ Breaker (One-and-a-Half)
  • Rated Short-Time Current: 50 kA / 63 kA (1 sec)
  • BIL (Impulse Withstand): 1425 kVp
  • Line Reactor: 50 - 80 MVAR Switchable/Fixed
  • Auto-Reclose Mode: 1-Phase & 3-Phase (1.0s dead time)

220 kV Switchyard HV Grid

  • Busbar Scheme: Double Main + Transfer Bus
  • Rated Short-Time Current: 40 kA / 50 kA (1 sec)
  • BIL (Impulse Withstand): 1050 kVp
  • Interconnecting ICT: 315/500 MVA, 400/220/33 kV (YNyn0d11)
  • Auto-Reclose Mode: 1-Phase & 3-Phase

132 kV Switchyard Sub-Transmission

  • Busbar Scheme: Double Bus / Main & Transfer
  • Rated Short-Time Current: 31.5 kA / 40 kA (1 sec)
  • BIL (Impulse Withstand): 650 kVp
  • Interconnecting ICT: 100/160 MVA, 220/132/33 kV (YNyn0d11)
  • Auto-Reclose Mode: 3-Phase Only

Comprehensive Relay Protection Matrix (IEC / ANSI Standards)

Redundant Main-1 & Main-2 numerical protection philosophy for 400 kV, 220 kV, and 132 kV bays.

Protected Bay / Asset Protection Tier ANSI Code Protection Function Tripping / Action Logic
400 kV Transmission Line Main-1 (IED-A) 87L / 21 Line Current Differential (Optical Fiber) + Distance Backup High-speed 1-pole/3-pole trip via Trip Coil-1; initiates AR (79)
400 kV Transmission Line Main-2 (IED-B) 21 / 21N / 85 Sub-cycle Distance Protection with PUTT/POTT Carrier + DEF (67N) High-speed 1-pole/3-pole trip via Trip Coil-2; blocks AR on Zone-2/3
400 kV Line Reactor Dedicated 87R / 64R / 63 Reactor Differential, Restricted Earth Fault, Buchholz & WTI/OTI 3-pole trip of Line CBs + Direct Transfer Trip (DTT) to remote end
220 kV Transmission Line Main-1 & Main-2 21 / 21N / 67N Dual Quadrilateral/Mho Distance Relays + Directional Earth Fault Zone-1 instantaneous 1-ph/3-ph trip; Zone-2 (350ms), Zone-3 (800ms)
132 kV Transmission Line Main + Backup 21 + 67/67N Numerical Distance Relay + Directional Overcurrent/Earth Fault 3-phase trip only; 3-phase Auto-Reclose shot (dead time ~1.0s)
400/220 kV & 220/132 kV ICT Main-1 & Main-2 87T / 64R Biased Percentage Differential + High/Low Impedance REF Trips HV, IV, and LV breakers simultaneously via Master Trip (86); Blocks AR
400/220 kV & 220/132 kV ICT Backup & Mechanical 51/51N / 24 / 63 IDMT Overcurrent, Overfluxing (V/Hz), Buchholz, PRD, OTI/WTI Alarm on Stage-1 (Gas/Temp); Master Trip (86) on Stage-2 / Surge
400 / 220 / 132 kV Busbars Distributed/Central 87B / 50BF Low-Impedance Busbar Differential + Local Breaker Backup (LBB) Trips all CBs connected to faulted bus zone within <20ms; blocks AR
